# Review Learning

Use this skill for periodic review or when deciding what to learn next.

## Review contract

1. Read the learner's goals, recent evidence, open review cues, and relevant subject notes.
2. Distinguish demonstrated performance from exposure, intention, and agent-authored material.
3. Test a small sample through unaided recall, application, comparison, or transfer.
4. Identify what is durable, fragile, blocked, or no longer useful.
5. Update priorities from observed performance and current goals.
6. Recommend the smallest next review or real-world application.

Do not manufacture progress scores from note volume. If no reliable evidence exists, say so and propose a cheap test.

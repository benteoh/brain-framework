# Review Learning

Use this skill for periodic review or when deciding what to learn next.

## Review contract

1. Read the learner's goals, recent evidence, open review cues, and relevant subject notes.
2. Distinguish demonstrated performance from exposure, intention, and agent-authored material.
3. Test a small sample through unaided recall, application, comparison, or transfer.
4. Identify what is durable, fragile, blocked, or no longer useful.
5. Update priorities from observed performance and current goals.
6. Recommend the smallest next review or real-world application.

Do not manufacture progress scores from note volume. If no reliable evidence exists, say so and propose a cheap test.

## Coach-written notes carry a debt

Step 2's distinction between demonstrated performance and agent-authored material does real work when the learner's chosen note mode has the coach holding the pen (see `learn`, "Who writes the notes"). Those notes read as knowledge and are not yet evidence of any: the learner has read a good articulation, which is exactly the condition that produces fluency illusion.

Treat them accordingly. A coach-written note is a claim awaiting a test, not a result — so prefer sampling from them when choosing what to review, test by unaided recall or transfer rather than recognition, and be willing to conclude that a well-written note describes something the learner cannot actually do. That conclusion is a useful finding, not a failure of the note.
